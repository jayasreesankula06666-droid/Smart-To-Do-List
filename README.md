# 📝 Student To-Do List

A beginner-friendly student project built with **HTML, CSS, and JavaScript**. Organize homework, assignments, revision, and everyday tasks in one simple place.

## ✨ Features
- Add tasks and mark them completed
- Filter tasks by All, Active, and Completed
- Delete individual tasks
- Clear completed tasks
- Automatically save tasks in browser local storage
- Responsive layout for desktop and mobile

## 🧰 Technologies
- HTML5 — structure
- CSS3 — responsive design
- JavaScript — task actions and filtering
- Local Storage — saves tasks in the current browser

## 🚀 Run the Project
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser.
4. Add tasks and try the filters.

No installation or server is required.
